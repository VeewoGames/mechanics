# 网页节点编辑器

本地服务从启动时固定的工作区根读写 JSON，显式参数优先，否则向上定位。悬停侧栏工作区名称可查看完整根路径；不连接游戏运行时，不使用浏览器缓存代替保存。界面为浅色极简样式：左侧文件目录，其余区域为画布或节点名词表；属性在需要时浮出，侧栏可以收起。

界面布局：侧栏顶部是项目卡片（点击切换项目，右侧是重新读取与项目设置），其下是关联项目入口和资源页签。主区域只有一行顶栏，从左到右是侧栏开关、「总览｜概念表｜机制图｜文档」工作视图、保存状态与保存按钮；顶栏没有文件标签条。打开过的机制列在侧栏的「已打开」页签里，按打开顺序排列，切换不会重排：单击立即切换，悬停后点 × 或按鼠标中键移出列表。列表最多保留 10 个，满了会自动移出最久没切到的一项，被移出的只是快捷入口，文件本身不受影响。同一项目内切换复用页面已读取的工作区，不重新读盘；需要外部最新修改时点项目卡片上的重新读取。当前文件的类型、名称、落地状态和文件路径显示在画布左上角；画布底部居中是工具条，左下是结构提示，右下是缩放。只浏览目录、尚未加载项目数据时，工作视图、保存和画布工具不显示。没有关联项目时，关联项目区只保留一行添加入口。

## 打开项目与加载数据

点击侧栏项目卡片打开「打开项目」面板：只有一个面板，列出最近项目，上方是筛选框和「打开文件夹…」。点最近项目即打开；点「打开文件夹…」唤起系统文件夹选择器，选定后同样直接打开，没有页签和二次确认。打开失败时面板保留并就地显示服务端返回的实际错误。行尾图标可置顶或从最近列表移除（不删除项目文件），当前项目标注「当前」。

网页「打开项目」及启动恢复先经共享准备入口：缺少工作区时自动初始化，已有工作区只补齐或修复包拥有的受管技能与工具，不覆盖领域文件、不创建领域会话。之后独立枚举磁盘目录；此目录投影不解析 JSON、不迁移、不赋予领域写入能力，也不恢复最近或默认图。随后自动尝试严格加载领域数据，成功后进入固定「总览」；损坏时目录仍可浏览并显示具体错误，修复后可重新打开。目录列表中的链接不跟随。

目录显示后会独立回读 `workspace.json` 中保存的项目显示名，不加载规则或打开图。坏规则文件不影响名称读取；元信息读取失败会明确提示，目录仍保留并暂以文件夹名标识。项目设置保存成功后，侧栏、项目标签和该项目的文件标签立即更新；刷新或重新打开目录重新读磁盘名称，不使用历史名称缓存。切换项目后迟到的名称响应不会覆盖新项目。

加载失败保留目录并显示具体错误；坏资源不能当作健康图编辑。连接中断、响应无法解析或超时不会触发自动刷新，页面保留错误与草稿；写入结果待确认时先重新读取核实，不重复提交。修复磁盘文件后重新读取目录，再明确打开图。

## 文件与图层

- 顶部「总览｜概念表｜机制图｜文档」切换工作视图；侧栏提供「总览｜机制库｜已打开」。机制库的「＋」新建机制，旁边可新建文件夹。组合浏览直接使用总览；网页不再提供已存视图、新建视图、视图自动保存或旧叠加迁移入口。
- 拖动侧栏右缘的分隔条可调整侧栏宽度（220–560px），双击恢复默认；聚焦分隔条后也可用左右方向键微调、Home 复位。宽度只记在本机浏览器，不写入项目文件；窄屏抽屉模式使用固定宽度。
- 根内任意普通目录的 `*.mechanic.json` 在界面称为「机制」，`mechanics/` 是默认落点。点击机制名称只显示该文件自身的节点和关系；机制模式不显示范围勾选框。
- 机制模式可修改关系，手动保存到当前机制。总览中的源规则只读，详情提供相关机制入口；打开机制编辑后，可通过顶部「总览」返回组合浏览。
- 单图标题显示落地状态：新图和所有迁移旧图均为「设计稿」，仅作者明确设置 `implemented` 后显示绿色「✓ 已落地」。再次点击侧栏当前机制名称打开「机制属性」，在「落地状态」下拉框切换设计稿/已落地，再点击保存；未保存时标题标注草稿。此标记是整张图的作者声明，不是运行时或逐条规则的验证结果；总览不汇总判定落地状态。
- 机制的连线图模式中拖节点修改该机制的局部位置并形成草稿；力导向模式和总览中拖节点只修改本页会话位置，不保存文件。
- 机制区及各级真实目录均可折叠，支持鼠标、Enter 或空格操作；按名称、ID、相对路径筛选。搜索时临时展开命中的目录，清除后恢复原折叠。筛选和目录折叠仅保留在当前页面，不改画布、勾选、文件或撤销记录。
- 总览显示「已选数 / 机制总数」。侧栏文字搜索不改变这个范围；新机制成功打开后会清除机制库筛选并展开所在目录，再次进入总览时新机制加入范围。
- 机制文件来自磁盘发现，按真实目录组织，不显示空目录占位。悬停文件名可查看完整相对路径。外部新增/移动后点侧栏右上角重新读取，无需手工登记。

## 总览：勾选机制直接浏览

总览是项目固定入口，首次进入默认选择全部机制。在左侧「总览范围」勾选机制，画布按这些机制合并显示；共享概念和共享规则各显示一次，规则的方向、符号与来源保留。范围搜索只筛选左侧候选，勾选才改变画布；「全选」和「清空」作用于全部机制，清空后显示空图。每项旁的「打开」进入机制单图编辑，顶部「总览」可返回浏览。

总览的筛选、拖动位置和重排结果只记在当前页面会话中，状态显示「总览 · 无需保存」，不创建 `.view.json`，不更新 `workspace.lastView`。切到其他页面再返回可继续浏览；重新读取时新机制加入范围，已经取消勾选的既有机制仍保持隐藏，删除的机制退出范围。刷新页面后会重新建立会话。总览不提供源规则编辑或撤销入口，修改规则需打开相应机制。

## 节点名词表

点击顶部「概念表」维护所有机制图共享的定义。表格参考 SJE Array 的紧凑表头、弱分隔线和内部滚动样式，但工具不依赖 SJE 或宿主代码。

点击行内「编辑概念」打开共享对话框，修改名称、概念定义、别名和标签；每行的 Agent 锁由用户显式切换，锁定后 Agent mutation 不得修改或删除该概念。点击「新增概念」或表尾「新增一行」打开新建概念对话框。稳定 ID 自动生成且只读，改名不改引用；名称与定义必填，未完整填写无法保存。顶部搜索按名称、ID、定义、别名或标签筛选，不修改文件。当前概念表没有跳到引用机制图并定位节点的行内入口；需从侧栏打开相应机制图。删除仍检查规则和视图引用，存在引用时不能直接删除。

概念表草稿归共享定义文件，机制图草稿归当前分析文件。切换前有未保存修改时，可保存、放弃或取消；页面只保留一份当前文件草稿。进入概念表不改变记住的分析文件、可见层和折叠状态，返回机制图继续原来的范围。保存定义后，所有引用图层显示新名称；修改概念文案不会清空图层折叠。按 Ctrl+S 或顶部保存按钮落盘。

## 建图

1. 点击侧栏机制区右侧「＋」，填写名称、文件 ID、分析范围和相对目录。支持中文嵌套目录；填 `.` 表示根目录。此操作创建实际 JSON 文件，不写额外登记清单。空工作区也可以直接创建首张图。
2. 在机制图点击「引用概念」，搜索并勾选需要引用的共享概念；名称、ID、定义、别名和标签均可检索，已引用项显示「已在当前图中」。搜索框 Enter 勾选首个可选结果，不自动新建。
3. 需要新概念时点击「＋ 新建」，名称从搜索词带入，填写概念定义，然后「创建并引用」。同名先列出可复用概念，只有明确勾选同名新建才允许另建；不按名称合并。
4. 点击「＋→」「−→」「？→」，依次点击源概念和目标概念，建立影响关系。两端必须已被当前机制引用。正向影响使目标沿增加方向变化；负向影响使目标沿减少方向变化；随机影响表示目标可能增加或减少，不表示概率。相反方向的关系独立。
5. **结构关系（is-a 与 part-of）不通过连线创建**：每个概念至多一个结构父概念，关系类型在 is-a（是一种，具体概念 → 上位概念）与 part-of（是其组成部分，局部 → 整体）之间二选一。在节点属性面板的「结构父概念」里先选关系类型，再输入名称、稳定 ID、别名或含义检索父概念；「新建概念 / 修改概念」对话框的「结构父概念」分组同样提供关系类型与父概念两个字段。已有父概念时切换关系类型会在一次提交里把原结构边替换成另一种，不需要先清除再重选。输入一个字符只匹配名称、稳定 ID 与别名，两个字符以上才覆盖含义与标签，命中按完全相同、前缀命中、其它命中排序；候选列表每项只显示名称与稳定 ID，描述在悬停提示里。打开下拉时输入框保留当前值的「名称（ID）」并全选，有当前值时候选首项就是「清除结构父概念」，点它即清除，不再弹二次确认。候选不会列出自身与结构后代（is-a 与 part-of 都算），禁止自连接与闭环（含两种关系混合成环），违反会被明确拒绝。结构关系默认不画连线，只在子节点内显示「is-a：父概念」或「part-of：整体」标签；已有结构父概念的节点在详情栏还提供「显示连线」开关，按当前文件把该概念加入或移出展开集合，展开后画出对应的虚线边。
6. **编辑概念只有一个界面**：机制图节点属性面板的「修改概念」、概念表格行的「编辑概念」、以及新建概念都使用同一套表单与同一组结构父概念字段。概念表的编辑按钮打开的就是这个共享对话框，提交时把概念定义与结构关系规则（is-a 或 part-of）一次写入（`definitions` + `rules` 同一事务，并同步清理受影响机制图/视图里被删规则的固定引用），因此不会出现「概念已改、is-a 丢失」或反过来的半提交。为避免概念一多就整表重排，概念表一次最多渲染 200 行，其余用「还有 N 个匹配概念，继续输入以缩小范围」提示；新保存或定位到的概念始终会出现在表里。对话框宽度随视口自适应，桌面视口下不超过 1040px，窄于该值时保留 32px 边距；编辑器内部两列布局，身份分组整行（名称与稳定 ID 并排、概念含义整行）、is-a 分组整行，不会横向溢出。对话框底部只有一排「取消 / 保存概念」，编辑器自带的那排按钮在对话框里不再出现；在对话框里改动即标记为未保存，关闭或切换文件前仍会确认。
5. 选中节点或边，在浮动属性面板直接修改规则文字、关系或符号；条件约束直接写入规则文字，未填写规则的连线显示为灰色，或移除引用。再次点击当前图层名称可编辑名称与范围。
6. 开启悬浮说明后，悬停允许解释的连线显示该连线的规则文字，保留换行；已有选择时仅解释当前高亮关系，未填写规则时不显示提示并清除上一条解释。连线图模式下悬停不改变连线样式，修改规则后提示随草稿更新。
7. 点击「保存」或按 Ctrl+S。画布上的修改立即成为草稿，只有保存成功才显示「规则已保存」。

引用窗口提交前，搜索、填写和批量候选仅保存在窗口内；取消不写定义，也不改机制草稿。最终提交先保存共享定义，再把所有引用和新位置作为一次操作加入原机制草稿；不会顺便保存原机制的修改。新节点在当前视野附近寻找空位，不强制适应画布或移动已有节点。仅引用已有概念不保存定义；撤销本次引用不删除已落盘的共享概念。大批量节点可能延伸到当前画面之外，可主动适应画布查看。

创建失败或结果待确认时，输入保留并暂停重复提交。「重新读取并核实」只核实，不自动重试：若本次稳定 ID 与内容已经完整落盘，继续引用而不重复创建；若尚未落盘，用户可再次明确提交。源机制改变或 ID 内容不一致时拒绝继续，可导出本次输入和机制草稿后人工合并。已保存但未能加入机制时提供「继续引用」。关闭失败窗口不会丢弃本次会话，再次点「引用概念」继续处理；切换文件前须完成，或明确「结束本次引用」，已经写入的定义不会删除。

这不是跨文件原子事务。被任一图层引用的共享定义禁止删除。移出当前层会同时移除该层连接此节点的边，不修改其他层或全局定义。总览不提供创建或引用概念入口，需要先打开相应机制。

## 保存与旧文件边界

规则编辑和连线图节点拖动可手动保存；连线图显式重排会自动保存当时的机制草稿。力导向位置只在本次页面会话中记忆，拖动和重排无需保存，也不会覆盖连线图布局。关闭机制文件、切换机制、返回总览或进入概念表时，若草稿只有连线图节点位置变化，会默认直接保存，不弹确认框；不需要松手后立即写盘。如还改过名称、规则、引用、颜色、结构展开等内容，继续询问保存、放弃或取消。选择放弃后，只有目标完整打开成功才替换草稿，打开失败仍保留原内容。自动保存失败会保留文件和草稿。关闭或刷新有草稿、未完成写入或写入结果待确认的浏览器页面时，浏览器仍会提示。保存失败先重新读取核实，不自动重复提交。

网页不再读取旧视图作为浏览模式，也没有「保存旧叠加为视图」「放弃旧叠加」或视图自动写回流程。项目原有 `.view.json`、`workspace.lastView` 和 `compositions` 不会被自动删除或转换。底层 Schema、文件校验、CLI 与导出合同仍保留，所以旧文件仍可能参与引用校验；本次退出的是网页功能，没有宣称全面移除视图协议。

文档页的导出设置只提供机制和文件夹来源。若旧导出设置包含视图来源，打开设置时会提示；仅在明确保存设置时移除这些来源，打开或取消不改文件。底层 catalog 与 CLI 仍可校验既有视图导出格式。

## 画布操作

力导向图以圆形节点显示概念，连接较多的节点略大，所有倍率使用同一张画布。名称显示在圆下方，缩小时优先保留连接较多的概念，并避开附近文字与节点；放大后名称下方显示结构标签和概念标签胶囊，放不下的合并为「+N」，遮挡附近内容时暂不显示。指向当前可见节点的结构标签可点击选中该节点。允许解释的节点可悬停查看名称、定义与别名，点击后按所选层数突出关联关系，默认一层。普通连线为中性灰细线，结构连线更淡；选中高亮范围内的关系按类型着色。

拖住节点时，节点保持在指针位置，多选节点保持拖动开始时的相对偏移；所在连通分量会受弹簧牵引，附近节点会避让。松手后继续平滑冷却，不相连的远处分量保持稳定，网页力导向图不吸附 20px 网格。一次拖动及其后续收敛合为一次会话操作，机制可一次撤销全部受影响位置，取消手势恢复拖动前布局。总览和机制的力导向位置均不写入文件。

大图缩小时仍可选择和拖动，放大后逐渐显示概念名称和标签，不切换绘制方式。高亮关系以源端粗深、目标端细浅表达方向。可先在左侧筛选机制范围，再用图内查找定位概念，或选中节点按当前层数突出关联关系。画布获得焦点后，可用方向键切换附近概念，Enter 选中。未选节点时，自动排版会重新生成起点并整理全图；选中节点后只整理选中范围。

机制选择模式中，双击空白画布打开「概念节点」面板，与工具栏同名入口一致。单击、框选、平移及带修饰键的操作不会触发；总览、概念表及无机制时不打开。节点双击仍用于连线。新增位置继续使用相机中心的既有排布策略。

节点属性中的「修改概念」弹窗直接编辑共享名称、概念定义、别名和标签；Agent 锁只在概念表中由用户单独控制，不在普通文本编辑弹窗中隐式改变。保存仅写概念表，所有引用同步生效；保留当前机制草稿、选择和画布位置。取消不写文件。遇到冲突或写入结果待确认时保留输入，可导出修改后关闭弹窗并重新读取核实。

机制节点的「追踪影响至」只列出当前机制范围中可达的直接、间接节点：正向、负向与随机影响均沿源到目标的方向；特化不属于影响追踪路径；排除自身和无关节点，循环不会重复列出。没有下游时显示提示。

机制选择模式下双击节点，以该节点开始连接，再点击另一节点创建一条边并退出连接状态。使用本页最后成功创建或修改的关系类型，初始为正向影响；只选中、切换工具、失败及撤销不改变记忆，刷新重置。Esc 取消，拖拽或 Shift 多选不会触发快捷连接，总览不允许建线。力导向连线按圆形边界接入，正反向及并行边用错开的曲线区分，不保存手选端点。

### 总览与机制图的力导向布局

力导向连线只有在开启「悬浮说明」时才响应悬停，显示强化样式与流动光点；关闭后经过连线不会改变样式或出现手型，已有悬停效果立即清除。关闭说明时按住 Shift 可临时启用，松开即恢复；点击选中关系的高亮独立保留。

机制图下方操作栏右端提供「力导向／连线图」分段开关，首次默认力导向。模式选择保存为当前浏览器的全局界面偏好，打开其他机制、切换项目或刷新页面后继续沿用。切到连线图可查看矩形概念卡片、正交连线和方向箭头，线上不显示关系符号；正负及关系类型仍可通过颜色、悬停提示和详情查看。该模式的节点位置随机制保存。切回力导向恢复本次页面会话中的布局，两个模式的位置互不覆盖。总览继续固定使用力导向。

总览和力导向模式的机制图以圆点和渐进名称呈现，所有倍率使用同一张 Canvas；放大后可见结构徽标与标签胶囊，力导向连线不再绘制关系符号或箭头。首次显示立即可以浏览，节点在后续画面中逐步整理，不等待布局结束才打开；稳定或到达收敛上限后停止。仅这次呈现不会把机制变成未保存草稿。会话内已经布局过的节点恢复原位，隐藏后再次显示不会重新打散；加入新节点时固定旧节点并安排新节点。点击选中节点后按当前层数突出关联，弱化其余内容；选中边突出该边和两端，取消后恢复。允许解释的对象可显示悬停说明与节点光环，不切换选择和高亮范围。普通关系为中性灰细线，选中高亮范围内的关系按类型着色。

点击节点后，右上「高亮」区可直接切换「1 层／2 层／3 层」，首次默认高亮一层；按不区分进入或发出方向的连接距离逐层扩大，多选取所有选中概念的邻域并集。点击其他节点即以新选择为起点，点「全部」高亮选中节点所在连通分量。其余节点和连线仍留在画布上并淡化，查找、节点计数和重排范围保持完整，切换层数也不移动相机或打断布局。「1 层／2 层／3 层／全部」统一保存为当前浏览器的全局界面偏好，切换总览、机制、项目或刷新页面后继续沿用，不写入游戏文件。

关系方向按「源端粗深 → 目标端细浅」阅读，类型按既有颜色区分；选中节点的出边突出，入边整体降低到六成不透明度。is-a 与 part-of 保留断续节奏。选中或悬停关系会强化该边，并让三个小光点从源流向目标；系统开启减少动态效果时，改为在距源七成处显示一个静止点。清除关系焦点后停止动画，普通关系保持 1px 灰线。已有选择时，仅选中概念及当前高亮范围内的关系提供悬停说明；选中关系时可解释该关系与两端概念。无关节点和关系不会弹出提示或出现悬停光环。清除选择后可自由悬停查看，切换选择或缩小高亮层数会立即隐藏不再相关的旧提示。

点击「自动排版」主动重排：没有选择或选择全部时重新播种全部可见节点，只选部分时严格固定未选节点。机制的力导向重排及拖动各形成一次可撤销的会话操作，撤销恢复操作前画面；这些操作不形成文件草稿，也不自动保存已有规则草稿。保存规则时只提交连线图坐标。总览两种操作也不写文件。模拟会逐步分离碰撞节点，已固定的节点不会为此移动。切换范围、模式或发起新计算会停止过时模拟；无效引用和坐标明确报错。模拟中保存、撤销或切换页面，会先结束当前这一笔会话操作。

连线在拖动中即时跟随节点，普通关系用直线，反向、并行关系和自环用曲线区分；源目标、关系类型和正负符号的规则含义不变，可在悬停提示和详情中查看。每次拖动都会唤醒所在连通分量，使关联节点实时响应；放开后逐渐停稳。连线不使用已存正交路线缓存，不保证避开其他节点或消除全部交叉。必要时可通过机制范围、选中节点后的分层高亮、图内查找和局部重排集中阅读注意力。

### 通用手势与取消

多选状态不保存，不提供批量删除；Shift＋左键框选仅在选择工具和画布空白处开始。右键平移在连线工具下也可使用，不产生连线。Esc、取消指针、失去捕获或窗口失焦会取消预览，不产生位置保存；手势期间不缩放。特化端点不能折叠；特化自连接和闭环明确拒绝。

## 文件安全与失败

同一工作区只允许一个服务持有 `.mechanics.lock`，浏览器多标签可连接同一服务。正常 Ctrl+C 关闭会释放锁。异常退出留下锁时，应确认无服务仍在使用该目录后手动清理；服务不凭 PID 自动抢锁。

每次保存按**本次写入涉及的资源**校验语义版本，并整体校验全工作区引用，然后使用同目录临时文件、flush、close、rename、回读确认。坐标、配色与连线路径属于展示数据，不参与版本比较。同一文件被其他写入者语义修改时返回冲突并点名文件，保留草稿；可先「导出 JSON」，再重新读取磁盘并手动合并。不提供强制覆盖按钮。

其他标签页保存别的文件、或打开图时补算坐标与连线路径，都不再改变本次保存所依据的资源版本；只有本次写入真正涉及的文件被语义修改时才会冲突。冲突提示中的「重新读取」与侧栏右上角刷新使用同一草稿保护；没有草稿可直接同步，有草稿会先提示处理。不会自动采用旧 revision 或悄悄重试。

新建机制图通过完整文件发布直接进入发现集合，不再另写清单。已有同名文件绝不覆盖；请求结果不明时应重新读取，不能自动重试。创建失败可能留下已经创建的空父目录；替换提交后确认失败或连接中断提示结果待确认。

只支持本地磁盘的单服务工作方式，不承诺外部编辑器并发写入的原子 CAS、掉电恢复、多文件事务、网络共享盘或多人协作。页面打开期间没有文件监听；需要读取外部最新修改时点击重新读取或刷新。保存期间不要让其他程序改写同一工作区。
