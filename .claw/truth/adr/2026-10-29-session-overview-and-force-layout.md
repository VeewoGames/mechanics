# ADR：固定会话总览与单画布力导向

## 背景

跨机制浏览应直接选择范围，机制编辑需要名称、方向与符号。静态求解不能在拖动时牵引关联节点，真实规模求解还曾阻塞打开约 28 秒。用户要求真正实时交互并取消网页视图兼容入口，后续确认以单画布承载全部倍率的力导向呈现。

## 决策

- 总览是固定非文件会话，首次全选机制，复用领域合成与稳定 ID 去重，筛选、位置和展开状态只归会话，不创建视图、不写 lastView。
- 网页退出 view/legacy 的打开、导航、最近标签、自动保存、迁移和文档导出视图选择。后端 Schema、CLI 和历史文件合同保留，不自动删除用户数据或引入破坏升级。
- 圆点采用 RAF 持续模拟，拖动固定节点并唤醒所在完整连通分量，目标温度 0.3，松手归零慢冷却。首屏打开不等待收敛，时限按活跃帧累计，后台暂停不消耗预算。
- 机制图在下方操作栏右端提供「力导向／连线图」分段开关，首次默认力导向，模式通过浏览器全局界面偏好 `mechanics:orthogonal-graph-mode` 跨机制、项目及刷新沿用；总览固定力导向。力导向坐标和撤销只归 `forceLayouts`／`forceHistory`，拖动、收敛与显式重排不写机制文件，也不自动保存规则草稿；保存规则保留连线图几何。连线图复用正交呈现与 Worker，独占机制文件的 `positions`、`projectionPositions` 和 `routeCache`。关闭或切换文件时，仅连线图坐标变化的草稿通过原保存入口直接提交；显式连线图重排仍自动保存，不新增拖动松手立即写盘。失败保留草稿并阻止关闭，其余内容变化继续确认。总览只改会话。
- 当前选择拥有高亮起点，不保留独立观察中心；1／2／3 层只扩大选中概念的高亮范围，默认一层，「全部」高亮所在连通分量，多选取并集。四种层数选项通过 `mechanics:graph-highlight-depth` 保存为当前浏览器全局界面偏好，跨总览、机制、项目及刷新沿用，由画布在完整结构展示投影上按无向最短连接距离计算。完整画布、搜索、计数、排版输入、相机与模拟生命周期不随层数变化，领域投影及文件协议不拥有该状态。
- 悬停不接管节点选择或高亮范围；力导向连线只有在有效悬浮说明开启时（含按住 Shift 临时启用）才强化允许解释的当前关系并按需显示流动，关闭立即清除边悬停，点击选中关系的高亮独立保留。已有选择时仅解释选中概念与高亮关系，选中边则可解释该边和两端；选择或层数变化立即使范围外提示及光环失效。
- 力导向所有倍率使用单张 Canvas2D，SVG 仅作 2D 上下文不可用时的回退；保留正交路径。普通关系用中性灰屏幕 1px 且不画方向标记，聚焦关系用既有类型色的锥形渐变表达源到目标，移除关系符号和箭头；入边整体乘 0.6，结构关系保留断续。选中或悬停边按需播放三个光点，减少动态效果时改为七成路程处静止点，名称和胶囊按屏幕空间避让。全图显式重排重新播种，但撤销及失败回滚仍以操作前当前画面为基线。性能验收必须使用浏览器和真实规模，跨浏览器环境数据不能直接计算改善比例。

## 备选方案

默认创建视图会使浏览产生写入，不采用。有限静态 WebCola 不满足实时牵引，已退出网页打开路径；无限运动妨碍阅读，因此交互后收敛停止。卡片和缩放切换 SVG 的方案已由圆点、渐进标签及单 Canvas 替代，以控制大图 DOM 和绘制开销；详细信息仍可经悬停及放大查看。底层视图合同有存量文件与 CLI 消费者，本次不删除或强制迁移。

独立中心与领域邻域裁剪会让层数操作改变画布和排版范围，已按用户纠正退出；采用当前选择直接驱动高亮，让点击后即可调节层数。未用悬停改变聚焦，避免注意力偏离选中对象；未把层数写入文件或机制引用，避免展示偏好改动语义。未对全部脏草稿自动保存：仅坐标变化须与基线严格比较，其余内容继续由用户决定；沿用既有保存入口以保留校验、冲突与失败保护。保留连线图以满足部分图更清晰的阅读需求；力导向模拟位置易变，故不与持久正交布局共用写入口。不新增模式协议字段，也不扩大自动保存触发时机。

高亮方向不继续依赖箭头和关系符号，改为锥形渐变；结构边保留断续以兼顾类型识别。未采用普通灰线的可选轻锥形，维持 1px 批量描边与远景安静。流动仅供选中或允许悬停边补充方向，复用合帧 RAF、几何与弧长采样缓存，避免无焦点时持续绘制；减少动态效果使用静止点。该选择仅改变呈现，不改变规则符号及 source／target 的领域合同。

## 后果

高亮层数同样复用浏览器本地界面偏好，不再按项目和画布上下文分别记忆，避免切换或刷新后重复选择；不写游戏文件或服务端偏好。`app.mjs` 的 `preferredHighlightDepth`／`changeGraphDepth` 读写该偏好，首次、无效或不可用存储默认一层，写入不可用时保留当前页面选择。四种选项及回退边界由 `tests/graph-focus.test.mjs` 固定。

模式选择复用浏览器既有界面偏好入口，不再按单图会话恢复，避免切换机制或刷新时反复选择；不引入游戏协议字段或服务端偏好字段。正交连线也移除线上关系符号文字，但继续用箭头、颜色、虚线及提示表达方向与类型，领域 `sign` 与规则语义不变。相关实现为 `app.mjs` 的 `preferredGraphMode`／`changeGraphMode`、`index.html` 的 `graph-mode-controls` 及 `canvas.mjs` 的正交 SVG 边创建。

总览刷新重建，不能当作持久命名组合。局部收敛不保证全图零重叠，即时连线不保证第三方节点避障或无交叉。当前实现及验证范围见[打开事务与实时模拟](../features/async-compute-and-opening-transaction.md)和[编辑器导航](../features/editor-navigation-and-layers.md)。锚点为 `src/web/overview.mjs`、`force-simulation.mjs`、`force-geometry.mjs`、`canvas.mjs`、`app.mjs`、`mechanic-files.mjs` 与 `src/domain/taxonomy-presentation.mjs`；`tests/graph-focus.test.mjs`、`tests/force-canvas-runtime.test.mjs`、`tests/position-close.test.mjs` 固定完整图上的选择高亮、悬停权限及位置保存边界。层数不触发排版，但运行中的模拟仍可自然改变坐标；验证层数稳定性须区分二者。源码完成不代表已发布。

### 高亮层数退出上下文会话记忆

先前按项目及画布上下文分别记住高亮层数；用户要求全局保存后，统一为当前浏览器的持久界面偏好。当前选择继续拥有高亮起点，完整图投影与注意力计算保持原边界，不因偏好持久化引入游戏文件字段。

<!-- dated: 2026-10-30 -->
### 模式选择转为浏览器全局偏好

先前按项目与机制在页面会话记忆图模式；现在用户选择跨机制、项目和刷新沿用。仅模式偏好持久化，力导向坐标和撤销仍归页面会话，连线图位置保存边界保持不变。正交线也不再叠加关系符号文字，箭头及语义提示保留。

<!-- dated: 2026-10-30 -->
### 力导向位置退出文件草稿

先前机制力导向拖动和显式重排沿用文件草稿与保存入口。模式切换恢复后，文件坐标明确只拥有连线图布局，力导向位置和撤销改归页面会话；规则草稿仍共用，原关闭或切换时的纯位置自动保存只作用于连线图，不扩展为松手立即写盘。

<!-- dated: 2026-10-29 -->
### 从独立中心筛选改为选中对象高亮

早期决策把点击选择与观察中心分开，并由领域显示投影裁剪邻域，「全部」用于恢复显示范围。用户澄清层数应扩大选中对象的高亮且保留完整图后，以当前选择和画布注意力替代独立中心及裁剪。悬停关系也明确退出着色加粗，已有选择时限制解释范围，以保持选中对象的阅读焦点。

<!-- dated: 2026-10-29 -->
### 从卡片及混合渲染改为单画布

早期保留卡片，并按节点数量和缩放切换 Canvas／SVG。单画布方案确定后，力导向改为圆点与渐进名称、胶囊，所有倍率只用一张 Canvas；正交卡片继续保留。拖动从有限邻域调整为完整连通分量保温，松手慢冷却，显式重排重新播种但保留操作前撤销基线。

<!-- dated: 2026-10-29 -->
### 从静态求解改为实时牵引

早期方案保留网页旧视图并以 WebCola Worker 有限求解代替实时模拟。用户指出拖动缺少关联响应，真实规模暴露打开阻塞，故以渐进模拟和增量渲染替代网页路径；底层旧文件合同保留。
