## 当前行为

- 顶部工作视图为「概念表｜机制图｜文档」。侧栏以「视图｜机制库｜最近打开」页签切换资源列表，页签下方一行是搜索框与新建按钮；「＋」跟随当前页签（视图页 `newView`，机制库 `newGraph`，另有新建文件夹），顶栏 `#new-view` 仅在旧叠加待迁移（`legacy`）时显示。实际文件路径不变，不在每个视图下复制机制树；workspace.json、统一定义文件和旧命名组合不作为导航项。磁盘机制后缀仍为 `.mechanic.json`，视图行不可勾选。
- 「打开项目」是单面板：列出最近项目，点一项即调用 `POST /api/project/directory` 并关闭；「打开文件夹…」才唤起原生目录选择器（`/api/directories/pick`），选定后同样直接打开。没有页签和预检确认面板；失败时面板保留并就地显示服务端错误。置顶/移除是行尾图标，仅改最近项目记录。
- 视图可删除：侧栏视图行悬停图标、视图详情页与视图模式顶栏都进入 `deleteViewDialog`，经确认后调用 `POST /api/view-delete`（`store.deleteView`）。服务端在同一次 `commitFiles` 中删除 `.view.json` 并清理 `workspace.json` 里指向它的 `lastView.viewId` 与视图导出选择，不触碰机制、规则或概念。删除当前视图前沿用草稿守卫，之后重置自动保存目标并打开仍存在的标签或第一张机制；自动保存阻塞时拒绝删除。Agent 的 `view delete` 仍在 `lastView` 引用该视图时拒绝（`VIEW_REFERENCED`），两条路径语义不同。
- 侧栏宽度是本机界面偏好：`#sidebar-resizer` 拖动、方向键或双击复位，范围 220–560px，写入 `localStorage` 的 `mechanics:sidebar-width` 并经 CSS 变量 `--sidebar-width` 生效；不写项目文件，窄屏抽屉模式固定宽度。
- 写入确认后侧栏必须显示最新文件列表：`renderSidebar` 在浏览项目与编辑项目是同一会话（`projectSessionToken` 相同）时把 `browserWorkspace`/`sourceProject` 对齐到最新 `workspace`；侧栏内随重绘生成的操作按钮（`data-folder-action`、`data-view-action`）的可用状态由 `updateStatus` 统一刷新，不能只在渲染时取 `busy()`。
- 节点卡片固定 166×62。第二行是一排胶囊（`nodeChipLayout`，`src/web/canvas.mjs`）：结构标签在前、概念标签在后，全部限制在卡片内宽，放不下的合并为「+N」并保留完整悬停文字；名称按估算宽度截断（`fitText`），无胶囊时垂直居中。页面 CSP 为 `style-src 'self'`，标签色只能经 CSSOM `style.setProperty('--tag-color', …)` 写入，`setAttribute('style', …)` 会被拦截并退化为黑色。
- 关联项目声明保存在源工作区 `.mechanics/references.json`，共享字段为关联 ID、名称、目标 workspaceId 与可选相对路径；本机绝对目录绑定单独保存在用户配置 `project-reference-bindings.json`。目标目录在另一台机器缺失时，列表保留声明并返回 `unavailable` 状态及错误消息，源工作区仍可读取；错配、不可用版本也由列表状态隔离。进入操作仅允许 `ready`/`migratable`。当前侧栏只渲染 `ready` 项，非 ready 项仅能在关联管理对话框发现；尚无侧栏重新定位入口。
